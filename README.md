# FixMyCity AI — From Complaints to Action

A lightweight civic-tech hackathon prototype. Citizens describe problems such as potholes, garbage, broken streetlights, water leaks, or safety concerns. The app categorizes the complaint and calculates a transparent priority score.

## Run
Open `index.html` in a browser. No backend or API key is required.

## Hackathon
Built as an Open Innovation prototype for HackDevengers 2.0.
